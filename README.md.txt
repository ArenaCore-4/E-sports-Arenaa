## 1. Project Overview

ArenaCore is a menu-driven University Esports Tournament Management System developed using the C programming language. It is designed to simplify and organize the management of university esports tournaments.

The system allows tournament organizers to manage players, create teams, handle tournament registrations, schedule matches, record results, generate leaderboards, and view tournament statistics. It also uses file handling to save and load data, allowing records to be maintained between program sessions.

## 2. Project Objectives

- To develop a C-based system for managing university esports tournaments.
- To implement player registration and team management.
- To organize tournament registrations and match scheduling.
- To record match results and maintain team leaderboards.
- To apply input validation and file handling for reliable data management.

## 3. Main Features

### Player and Team Management

- Register new players.
- Create and manage teams.
- Search and update player and team records.
- Delete teams according to system conditions.

### Tournament Management

- Create and manage tournaments.
- Register eligible teams.
- Manage tournament capacity.
- Maintain a waiting list and handle team withdrawals.

### Match Scheduling

- Schedule tournament matches.
- Manage match-related information.

### Results and Leaderboard

- Record match results.
- Update team performance records.
- Display leaderboard information.

### Reports and Statistics

- Generate tournament summaries.
- Display relevant team and tournament statistics.

### Save and Load Data

- Save system records using file handling.
- Load previously saved records when required.

## 7. How to Compile and Run

1. Open the source code in Dev-C++ or another C IDE.
2. Compile the program.
3. Run the compiled application.
4. The main menu will appear.
5. Select the desired option by entering its corresponding menu number.
6. Follow the on-screen instructions to manage tournament activities.

## 8. Main Menu

ArenaCore provides the following main menu options:

1. Player and Team Management
2. Tournament Management
3. Match Scheduling
4. Results and Leaderboard
5. Reports and Statistics
6. Save/Load Data
7. Exit

## 9. Data Storage

ArenaCore uses C file handling to save and retrieve system records. This allows users to preserve tournament information and access previously saved data in later sessions.

The data files are created according to the file paths and names specified in the source code.
